Privacy Policy

Last updated: 22 October 2026

What this application is

Empire Archive Uploader is a private application owned and operated by Hamza Ali Basra. It is used for one purpose only: uploading and scheduling videos to his own YouTube channels (Empire Archive TV and Fortunes & Felonies) through the official YouTube Data API. The application is not offered to the public, has no other users, and is never used to access anyone else’s account or data.

What the application accesses

With the channel owner’s own authorization, the application can: upload video files, set titles, descriptions, tags and thumbnails, schedule publishing times, and read basic channel and video status so uploads can be verified. Nothing else is accessed.

What the application does not do

The application does not collect, sell, rent, trade, or share personal information. It contains no advertising, no analytics trackers, and no third-party data sharing of any kind.

Data storage

Authorization tokens are stored securely on the owner’s private system and are used only to operate the owner’s own channels. No personal data about viewers, subscribers, or any other person is stored by the application.

Revoking access

Access can be revoked at any time from the Google Account security settings (Third-party access) at myaccount.google.com/permissions. Revoking access immediately stops the application from acting on the channel.

Google API Services disclosure

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
